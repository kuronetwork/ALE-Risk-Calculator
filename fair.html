Methodology Guide

This tool uses OpenFAIR™ standard calculations with Monte Carlo Simulation.

1. Beta-PERT Distribution

Unlike simple averages, we use Min/Most Likely/Max inputs to create a smooth probability curve (Lambda=4). This accounts for uncertainty in your estimates.

2. Event-Driven Logic

Risk = Frequency x Magnitude. We treat risk as discrete events using a Poisson Distribution for frequency, ensuring rare high-impact events are modeled correctly.

3. FAIR Calculation Formula

LEF = TEF × Vulnerability

LM = Primary Loss + (Secondary Loss × Sec. Prob)

AAL = Σ(LEF × LM) / Simulation Runs

VaR 90% = 90th percentile of annual losses

4. ROSI Calculation

When Mitigating Controls are configured:

Vuln (after) = Vuln × (1 - Effectiveness%)

Risk Reduction = AAL (before) - AAL (after)

ROSI = (Risk Reduction - Control Cost) / Control Cost × 100%

5. Monte Carlo Runs

Each "run" simulates one year. More runs produce more stable statistics:

  • 1K: Quick preview, less stable tail values
  • 10K: Recommended balance of speed and accuracy
  • 50K: High precision for formal reports
